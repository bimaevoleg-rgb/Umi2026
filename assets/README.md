# Игровой ассет

Сюда положите файл игры `index.html` (вся игра «Числята: Волшебные острова» —
один офлайн-HTML, ~3 МБ, со встроенными фото-ассетами).

Файл — тот самый `index.html` из офлайн-версии игры
(архив `Числята_ver1_офлайн.zip` / папка `app/`).

После копирования:

```bash
git add assets/index.html
git commit -m "Добавлена игра (assets/index.html)"
git push
```
